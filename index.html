Acerca del proyecto

Proyecto: Sistema de Gestión de Pedidos para WEB-Cántabra.

Autor: Jhordan QD Curso: Ingeniería de Software y Metodologías Ágiles · Metodología: Scrum con tablero Kanban en Asana.

Este prototipo permite demostrar registro de pedidos, control de disponibilidad, alternativas, validación simulada de pagos, preparación, despacho, entrega y cancelación.

Los datos se guardan únicamente en este navegador mediante localStorage. No hay servidor, autenticación real, envío de correos ni pasarela de pagos. Es un prototipo para demostración académica, no un sistema listo para producción.
